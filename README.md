🎬 VJ Edit Point – Premium AI Video Editing & Album Design Website

A high-end, single-page, luxury website built for VJ Edit Point, showcasing premium AI-powered video editing, wedding films, and album design services with a cinematic user experience.

This project focuses on modern UI/UX, smooth animations, WhatsApp-based service ordering, and mobile-first responsiveness — all built using HTML, Tailwind CSS, and Vanilla JavaScript.
